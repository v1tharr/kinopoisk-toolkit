# kinopoisk-toolkit

Юзерскрипт для Tampermonkey, который возвращает на Кинопоиск то, чего не хватает в разделах
**«Оценки и просмотры»** и **«Буду смотреть»**: нормальные фильтры, таблицу и выгрузку списков для ИИ.

Неофициальный, к Кинопоиску отношения не имеет. Работает только в вашем браузере и только с вашей сессией.

## Установка

1. Поставьте [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [kinopoisk-toolkit.user.js](https://raw.githubusercontent.com/v1tharr/kinopoisk-toolkit/main/kinopoisk-toolkit.user.js) — Tampermonkey предложит установить скрипт.

## Что умеет

На страницах `/user/<профиль>/movies/…` появляется кнопка **Toolkit**. Она открывает окно поверх страницы.

- **Все записи сразу.** Сайт показывает по 20 карточек на страницу, скрипт сам загружает все страницы и кэширует их в `localStorage`. Кнопка «Обновить» перезагружает список.
- **Фильтры:** поиск по названию, фильмы/сериалы, жанр, диапазон моей оценки, диапазон рейтинга КП, диапазон годов.
- **Сортировка** по любой колонке.
- **Таблица или плитка.**
- **Рейтинг КП и все жанры.** Берутся из данных, которые страница и так отдаёт вместе со списком, поэтому отдельных запросов не требуется.
- **Для ИИ.** Кнопка «Для ИИ» собирает текст из ваших оценок и списка «Буду смотреть» с запросом («что посмотреть сегодня…») и копирует его в буфер. Вставьте его в любой чат. Можно выбрать, какие списки включить, и ограничить открытый список текущими фильтрами.

Формат выгрузки — по строке на фильм:

```
Муха (1986, ужасы, фильм) — моя 7, КП 7.4
```

## Ограничения

- В данных списка нет стран, режиссёров и длительности, поэтому фильтров по ним нет.
- Парсер опирается на `data-tid` карточек Кинопоиска и на данные, встроенные в страницу (`__ssr_initial_data`). Если сайт поменяет разметку, колонки могут опустеть — см. блок «Кинопоиск: разбор страниц» в начале скрипта.
- Если Кинопоиск покажет капчу, скрипт остановится и сообщит об этом. Откройте сайт в соседней вкладке, пройдите капчу и повторите.
- Большие списки в выгрузке занимают много места (несколько сотен строк на список). Если упираетесь в лимит чата, ограничьте выгрузку фильтрами.
